# 🦁 LionBeat System

**LionBeat System** es una plataforma web creada por y para atletas de rendimiento híbrido. Su objetivo es unificar entrenamiento, nutrición y mentalidad en un solo espacio, optimizando el rendimiento con tecnología.

## 🚀 Objetivo del Proyecto

Desarrollar una aplicación web funcional como parte del ciclo DAM y Máster Fullstack, aplicando conocimientos técnicos reales sobre una idea personalizable y escalable.

## 🔧 Funcionalidades principales (versión MVP)

- 📅 Planificador de entrenamientos semanales
- 🍽️ Registro nutricional diario con recetas simples
- 📊 Seguimiento de progreso (entrenos, peso, sensaciones)
- 🧠 Test de fortaleza mental (inspirado en Matt Fitzgerald)
- 👥 Panel de comunidad / feedback

## 🧱 Tecnologías a utilizar

- **Frontend**: React, TailwindCSS
- **Backend**: Node.js, Express
- **Base de datos**: MySQL
- **Autenticación**: JWT + Firebase Auth (si se usa)
- **Despliegue**: Vercel + Railway
